# Bishal Regmi — Portfolio

Personal portfolio for Bishal Regmi, a Computer Science student at Kent State University working across software engineering, cybersecurity, AI-assisted analytics, and infrastructure.

## Featured work

- AI-Assisted Network Analytics Platform
- Internal Security Audit & Risk Assessment
- Data Breach Simulation & Recovery
- Network & Security Operations

The internship work is deliberately sanitized. No confidential infrastructure, findings, credentials, or company reports are included.

## Stack

React, TypeScript, Vinext, Vite, and Cloudflare-compatible Sites hosting. Content is centralized in `app/content.ts`.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

The repository includes `.openai/hosting.json` and is ready for Sites deployment. Set `NEXT_PUBLIC_SITE_URL` to the production URL so the sitemap emits the canonical homepage. A custom domain can be connected later without code changes.
