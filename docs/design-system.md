# Design system

## Concept
“Systems” connects software, security, networks, and AI. The visual language uses nodes, signal paths, numbered sequences, and disciplined editorial layouts without turning the portfolio into a dashboard.

## Palette
- Paper `#F2F3ED`: warm neutral canvas
- Ink `#111A17`: primary type and dark sections
- Forest `#0D3329`: brand field
- Signal `#D6FF68`: action and evidence accent
- Muted gray-green: supporting copy and rules

## Typography and layout
Manrope carries the editorial voice; DM Mono labels evidence, status, and system detail. Large left-aligned headlines, thin rules, generous space, and alternating light/dark sections create rhythm.

## Interaction
Motion is limited to the hero system orbits and smooth anchor navigation. Both stop when reduced motion is requested. Links use clear text, focusable native controls, and visible contrast.
